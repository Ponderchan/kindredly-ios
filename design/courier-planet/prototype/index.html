Wren 的动作(星球不自己转)

  • 在家:趴在最上面睡,有呼吸。你一拨她就醒,逆着小跑留在原地;拨猛了飞起来再落回,落地一个星星眼,过一会儿又睡。
  • 在路上:整个画面只有她在动。叼着信绕星球飞,会飞到球后面。你拨星球,她被顺着带一下,前倾、身后几道风。
  • 在对方窗台等:站在星球右肩上,脸朝外。隔几秒回头看你一眼、跺一下脚。
  • 带信回来:叼着信飞进来,落在最上面,蹦三下,信放在脚边。之后隔几秒蹦一下,直到你去读。
  • 休息日:星球两边立起两道门柱,她空着手一圈一圈穿过去,身后一串小点。她说的是线上那句「Day off. I'm doing laps between the pillars.」,按钮从 Open 变成 Play,点了进小游戏。
  • 点她:跳一下,换一个表情。
  • 这些都只是把现有的六张图移动、倾斜、压扁,不用新画。门柱是线上休息日那张卡片上已有的样子。

她的卡片:星球、她的话、她的衣服

  • 气泡:她的话从她嘴里说出来,尖角跟着她走。原来那条横条可以切回去对比。
  • 皮肤那一排四格,默认的不算:两个颜色、两个穿戴;一个免费、一个有了 kindred 就能用、两个 First Class。具体哪一件会轮换,点右边「换一批」看。正在穿的那件一直留在这一排。
  • 点 Moss,星球上的她当场换成绿色;再点一下换回默认。First Class 的两格是金色虚线加小锁。
  • 下面才是 Aura、Stamps 两格和写作报告。三格各用一个颜色:沙色、淡蓝、淡绿,都是 App 里日历心情已经在用的颜色。

星球页:一封信一张回执

  • 一次只看一张。左右滑换下一封,星球转到那枚邮票;点球上的邮票,回执跳到那一封;自己拨星球,停下时正对哪枚邮票,回执就换到哪一封。
  • 带回来的信:切到「带信回来」再进星球页,它直接停在被回的那一封上。回执是线上那三行,多一个去读的按钮。
  • 邮戳:有人回过的信,邮票上盖一个邮戳。这是我对「通信对象的窗」的替代。
  • 灯:一盏灯是一位读过这封信的陌生人。白天小亮点,傍晚和夜里发光。
  • 缩放:只在星球页。双指捏合、滚轮、双击,或右下角的加减号。放大后邮票变大,每枚下面显示日期。
  • 入口:右上角小按钮,或信使详情页里的 Track。全部的信还在 My letters。

哪些是真的

  • 四个时段的配色、Wren 的六个姿势、六枚邮票、四个皮肤小图、她说的每句话、回执上的措辞,都取自线上 App 和官方素材。
  • 头像行、写作报告那一行、底栏、信使详情页是线上截图,用的是默认主题(白底)。
  • 「被多少陌生人读过」线上已经有:My letters 里每封信旁边那只眼睛。只有人数,不显示是谁。
  • 例外:「在路上」时她说的两句是我提议的大白话版本,线上还是原来那句「still hunting for the right window」。
  • Moss、Peach、Night、Mist 四种颜色的鸟,是用官方那张图按 App 里各皮肤的配色换色出来的。
  • 名字、日期、每封信的读过次数、邮票落在哪里是示意。原型里穿戴(帽子、围巾)点了不会真的戴到星球上的她身上,First Class 的穿戴用的是线上锁着时那张淡色的图。
