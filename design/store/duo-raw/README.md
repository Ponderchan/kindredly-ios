# iPhone Duo, inner screen: raw captures

Real screenshots from the iPhone Duo simulator (iOS 27.2), inner screen open flat, 2853 x 2007
(the inner display's size in landscape; App Store Connect takes either orientation for the Duo's
inner screen, 2007 x 2853 upright). Taken 2026-11-13 from branch courier-planet with the status bar
set to 9:41.

They come from a development build: the grey round gear at the top right is the dev client's own
button and is not in the app. Retake them from a release build (or crop the gear out) before they
go into a store set. The account is the demo guest: the letters, kindreds and notes are the demo's.
