hey app review 👋

tl;dr kindredly = slow anonymous pen pals. you write one letter, a few strangers who write kinda like you get it, replies take hours or days. on purpose, not a bug lol

no demo acct needed: tap "Just looking →" on the first screen. apple / google / email code sign-in work too.

whats new in 1.2.2:
- Kindreds tab rebuilt (All / Kindreds / Pen pals). pull down or tap the thin line under the title to open the orbit
- Wren's desk = top row. ask how something works -> an animated how-to card plays
- long-press menus on rows + letters (copy / translate / report / block)
- tap a photo -> fullscreen
- take back a line within 2 min. rooms only exist after 5 letters each way so you prob wont reach one in review, sorry

moderation (the imporant bit):
- 18+ at signup
- report + block on every letter, line, row and conversation. block is instant and two-way
- 3 diff people report the same writer -> that writer cant send letters anymore, automaticaly
- open letters from Compose go thru an automated safety check before delivery
- hello@kindredly.io · https://kindredly.io/support

IAP: First Class monthly / annual (auto-renew) + Cofounder (one-time, non-consumable)
